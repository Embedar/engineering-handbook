# Engineering Handbook

> Personal engineering workflow for software, firmware, embedded systems, robotics and electronics projects.

---

## Purpose

This repository contains my engineering methodology, documentation templates and project planning framework.

The objective is to ensure every project follows the same professional workflow from idea to deployment.

---

## Workflow

```text
Idea
    ↓
Project Brief
    ↓
Requirements
    ↓
System Architecture
    ↓
Design
    ↓
Project Planning
    ↓
Repository Structure
    ↓
Implementation
    ↓
Testing
    ↓
Documentation
```

---

## Repository Structure

```text
templates/
    Documentation templates

diagrams/
    Draw.io templates

guides/
    Development guides
```

---

## Philosophy

- Documentation before implementation.
- Architecture before code.
- Decisions must be documented.
- Only create what the project actually needs.
